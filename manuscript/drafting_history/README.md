# drafting_history/ — superseded planning and drafting records

**None of these are the manuscript.** The live paper is the Google Doc
`1cO5ZStbp9b3cb6vb9s6H2YfbprYGikXBvFHQR7gROjo`; it has been the source of truth
since 2026-08-20. Every file here predates or feeds that Doc, and several carry
numbers the Doc has since superseded. Do not quote from them.

They are kept because they record *why* decisions were made, which the Doc does
not: which analyses were cut and on whose advice, which figure compositions were
tried, and which numbers were checked against which source file.
